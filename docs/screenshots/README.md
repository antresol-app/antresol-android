# Screenshot gallery

Rendered by the Robolectric live UI tests (`TvLiveUiTest`, `MobileLiveUiTest`, `MobilePlaybackLiveUiTest`) against a
real Antresol 0.3.0 server with its small test library, signed in as the Admin profile. Regenerate with
`scripts/update-screenshots.sh` (needs the server; see the script header).

Notes:
- The test library has almost no posters, so most artwork is the app's own title-on-gradient placeholder.
- Robolectric decodes no video, so the player shows its controls over black; comic pages do not decode either, so
  the comic readers are not in the gallery.
- TV shots show the D-pad focus (the white pill or the lifted card).
